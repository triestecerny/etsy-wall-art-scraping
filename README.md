# Etsy Wall Art Data Acquisition & EDA

This repository contains the original dataset, data collection scripts, and exploratory data analysis for my STAT 386 project analyzing Etsy minimalist wall art listings.

## Repository Contents
- `etsy_wall_art_data.csv`: The curated dataset containing 250 observations and 5 features (`title`, `price`, `review_count`, `is_bestseller`, `is_digital`).
- `generate_data.py`: The Python script used to curate and structure the dataset.
- `eda.py`: The Exploratory Data Analysis script generating summary statistics and distribution plots.
